## Structural findings

The static topology is a bracket encoding. Parentheses represent biological
bifurcations. Connected brace scaffolds encode groups OneZoom marks as
polytomies; collapsing each scaffold restores its biological child frontier.

| Measure | Count |

| Leaves | 2,228,001 |
| Display internal nodes | 2,228,000 |
| Biological internal nodes after brace collapse | 355,429 |
| Biological bifurcations | 265,546 |
| Genuine multifurcations with at least 3 children | 89,883 |

The leaf total agrees with the count rendered by the live OneZoom root page.
The two-child brace groups are retained as a source annotation but counted as
bifurcations for biological degree statistics.

The snapshot includes dates for 15,566 internal nodes and extinction dates for
5 leaves. These counts are presence statistics only; they do not yet establish
whether OneZoom IDs and dates align with normalized database records.

## Verified database schema

The current OneZoom
[database model](https://github.com/OneZoom/OZtree/blob/13580c42f5f320c7bb05499049806b861f3288b8/models/db.py)
defines these relevant operational tables:

- `ordered_leaves`: implicit ID, `parent`, `real_parent`, scientific name,
  extinction date, OTT/Wikidata/EOL and other external IDs, raw and adjusted
  popularity, popularity rank, IUCN IDs, and price metadata.
- `ordered_nodes`: implicit ID, `parent`, `real_parent`, nested-set boundaries,
  scientific name, age, rank, OTT/Wikidata/EOL and other external IDs,
  popularity, representative-image taxon IDs, IUCN descendant counts, and the
  most popular descendant leaf.
- `vernacular_by_ott` and `vernacular_by_name`: language, preference, source,
  source ID, and update metadata for common names.
- `images_by_ott` and `images_by_name`: image source, source ID, rights,
  licence, quality, and update metadata.

`real_parent` is explicitly documented in both core tables as the parent before
polytomy breaking; negative values mark polytomy membership. The static brace
audit validates that display-oriented polytomy scaffolding is substantial and
must not be used as biological depth.

## Limitations and next gate

The static snapshot contains complete topology and sparse dates, but not the
complete names, OTT mappings, popularity values, vernacular names, or image
licensing records needed for gameplay. OneZoom's current
[developer guidance](https://www.onezoom.org/developer) asks downstream
projects to contact OneZoom for a public production SQL dump.

No source or derivative is cleared for promotion to the tracked gameplay bundle
yet. Redistribution and attribution requirements remain review gates.
